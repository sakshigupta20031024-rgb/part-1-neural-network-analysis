Q. What role do weights and biases play in the model?

Weights and biases help the neural network learn patterns from the data. 
Weights decide how important each input feature is, while biases help adjust the final output so the model can make better predictions.

Q. Why is an activation function required?

An activation function is required because it helps the neural network learn complex relationships in the data. Without activation functions, the model would behave like a simple linear equation and would not learn properly.

Q. What happens when learning rate is too high or too low?

If the learning rate is too high, the model learns too quickly and may miss the correct solution. If the learning rate is too low, the model learns very slowly and takes a long time to improve.
